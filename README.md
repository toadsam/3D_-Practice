# 3D Practice

Unity 3D 환경과 에셋 배치를 연습하기 위한 프로젝트입니다. 자연물, 지형, 오브젝트 에셋을 활용해 3D 씬 구성과 렌더링 설정을 실험합니다.

## 프로젝트 개요

`3D_-Practice`는 Unity에서 3D 공간을 구성하는 방법을 연습하는 저장소입니다. 나무, 풀, 꽃, 지형 관련 에셋과 예제 스크립트를 활용해 씬 배치와 환경 표현을 익히는 데 초점을 둡니다.

## 주요 내용

- Unity 3D 프로젝트 구조 학습
- 지형/자연물 에셋 배치 실험
- 렌더 파이프라인별 에셋 호환성 확인
- 예제 씬과 샘플 스크립트 확인

## 기술 스택

- Unity `2022.3.2f1`
- C#
- Unity Terrain
- Unity Package Manager

## 폴더 구조

```text
.
├── Assets/
│   ├── Conifers [BOTD]/
│   ├── Grass And Flowers Pack 1/
│   └── Scenes/
├── Packages/
├── ProjectSettings/
└── README.md
```

## 실행 방법

1. Unity Hub에서 `2022.3.2f1` 버전을 설치합니다.
2. 저장소 루트 폴더를 Unity 프로젝트로 엽니다.
3. 패키지와 에셋 임포트가 완료될 때까지 기다립니다.
4. `Assets` 아래의 예제 씬 또는 작업 씬을 열어 실행합니다.

## 학습 포인트

- 3D 에셋을 프로젝트에 임포트하고 배치하는 방법
- 환경 오브젝트를 씬에 구성하는 방법
- Unity 프로젝트 설정과 패키지 구조 이해
- 에셋 패키지의 예제 스크립트와 샘플 씬 확인

## 개선 아이디어

- 직접 만든 씬 이름과 목표 정리
- 완성 화면 스크린샷 추가
- 사용한 외부 에셋 출처 정리
- 카메라, 조명, 지형 설정값 문서화
